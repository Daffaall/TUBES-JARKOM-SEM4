## Implementasi dan Analisis Kinerja Sistem Client Proxy Server Berbasis Socket Python: Evaluasi Protokol TCP/UDP dan Parameter Quality of Service

### Deskripsi
Project ini merupakan tugas besar mata kuliah Jaringan Komputer Modul 8 yang mengimplementasikan arsitektur Client–Proxy–Server menggunakan socket programming Python. Sistem mendukung komunikasi menggunakan protokol TCP dan UDP untuk melakukan analisis performa jaringan berdasarkan parameter Quality of Service (QoS).
